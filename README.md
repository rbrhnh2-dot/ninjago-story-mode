# Ninjago 3D: Spinjitzu City (Fan Game)

An unofficial browser-based Ninjago fan game with Story Mode and Sandbox.

## Deploy to Render

Create a **Static Site** connected to this repository:
- Build Command: `echo "no build needed"`
- Publish Directory: `.`

The game is a static HTML app. Three.js is loaded from a CDN, so an internet connection is needed for the 3D engine.

## Add to your phone home screen

Open the deployed HTTPS site in Safari on iPhone, tap Share, then **Add to Home Screen**. On Android, use the browser menu and choose **Install app** or **Add to Home screen**.
