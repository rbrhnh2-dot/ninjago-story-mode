# Ninjago 3D (fan game)

Unofficial fan project. Not affiliated with LEGO. Do not sell.

## Deploy on Render.com (Static Site)
1. Create a new GitHub repo and upload everything in this folder (index.html at the top level).
2. On render.com: New -> Static Site -> connect the repo.
3. Build command: leave empty (or `echo skip`). Publish directory: `.`
4. Click Create Static Site. Open the .onrender.com link.

(render.yaml is included, so you can also use New -> Blueprint.)

## Add to Home Screen
- iPhone: open the link in Safari -> Share -> Add to Home Screen.
- Android: open in Chrome -> menu (3 dots) -> Add to Home screen / Install app.
- PC: Chrome/Edge address bar -> Install icon.

The game loads three.js from cdnjs, so the device needs internet.
