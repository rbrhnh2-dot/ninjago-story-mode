# Ninjago 3D (fan game)
Unofficial fan project. Not affiliated with LEGO. Do not sell.

## Deploy on Render.com (Static Site)
1. Create a GitHub repo and upload ALL files from this folder (index.html at the top level).
2. Render -> New -> Static Site -> connect the repo.
3. Build command: leave empty. Publish directory: `.`
4. Create Static Site, then open your .onrender.com link.
(render.yaml is included, so New -> Blueprint also works.)

## Add to Home Screen
- iPhone: open the link in Safari -> Share -> Add to Home Screen.
- Android: Chrome -> menu (3 dots) -> Install app / Add to Home screen.
- PC: Chrome/Edge -> Install icon in the address bar.

After the first load the game is cached, so it can open offline.
Settings and saves are stored on the device (localStorage).
